# 🌸 CycleCare - Smart Menstrual Tracker & Hormonal Wellness Hub

> An intuitive, privacy-conscious menstrual cycle prediction and hormonal wellness application.

🔗 **Live Application:** [https://cyclecare-app.vercel.app](https://cyclecare-app.vercel.app)

---

## ✨ Key Features

- 💧 **Smart Cycle Prediction:** Automated calculation of cycle day, next period arrival countdown, ovulation day, and fertile window using standard clinical cycle models.
- 🌿 **Phase-Based Hormonal Wellness:** Dynamically detects the active cycle phase (**Menstrual**, **Follicular**, **Ovulation**, or **Luteal**) and provides actionable insights on:
  - 🥗 **Nutrition & Cravings**
  - 🏃‍♀️ **Movement & Exercise**
  - 💆‍♀️ **Self-Care & Mental Wellness**
  - 🧬 **Hormonal Fluctuations**
- 📝 **Daily Symptom & Mood Logger:** Multi-select chips for tracking emotional state, flow intensity (spotting to heavy), physical symptoms (cramps, bloating, headaches), and personal notes.
- 💧 **Interactive Hydration Tracker:** Visual daily water intake tracker with 8-glass goal tracking.
- 📅 **Interactive Calendar:** Visual highlights for active period days, upcoming predictions, ovulation day, and indicator dots on days with recorded logs.
- 🔒 **Offline-First Storage:** Fast, responsive client-side persistence using `localStorage`.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+)
- **Storage:** Client-side LocalStorage
- **Deployment & Hosting:** Vercel Global Edge CDN with SSL
